# Adivina el Número (The Guessing Game)

Un juego clásico de consola escrito en Python donde debes adivinar un número secreto entre 1 y 50.

## Cómo Jugar
1. El programa elige un número al azar.
2. Tienes **5 vidas** para adivinarlo.
3. El juego te dirá si el número es mayor o menor.

## Requisitos
- Python 3.x

## Ejecución
```bash
python adivina_el_numero.py
```
